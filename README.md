# 📈 Stockify

### Live WebSite Demo
https://stockifydemo.netlify.app/

**Stockify** is a full-stack web application designed for users to track inventory, manage stock portfolios, and perform financial analytics seamlessly. 

The project combines a robust and secure backend architecture with a modern, responsive frontend interface.

---

## 🛠️ Tech Stack & Architecture

### **Backend**
* **Framework:** C# / ASP.NET Core Web API
* **ORM:** Entity Framework Core
* **Database:** SQL Server
* **Authentication:** JWT (JSON Web Tokens)
* **IDE/Tools:** Visual Studio 2022 / VS Code

### **Frontend**
* **Library:** React.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Tools:** Vite / Axios

---

## 🚀 Key Features

* 🔐 **User Authentication:** Secure Sign-Up and Login workflows powered by JWT authentication.
* 📦 **Inventory & Portfolio Management:** Real-time stock tracking, item creation, updates, and deletion.
* 📊 **Financial Analytics:** Interactive portfolio summaries, valuation metrics, and detailed data tables.
* ⚡ **Advanced Filtering:** Fast and responsive search and filter mechanisms for stock assets.
